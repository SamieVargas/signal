# Golden set

Thirteen synthetic accounts, one per directory. Each has:

- the input documents, in the formats the app accepts (`.txt`, `.md`, `.csv`,
  `.vtt`, plus a `.png` chart or `.pdf` deck in three cases)
- `account.json`: the account name, primary contact as the CSM knows it, ARR,
  and days to renewal, passed to the pipeline the way the CLI flags are
- `expected.json`: the hand labels the runner scores against

The labels were written on 2026-09-21, before any pipeline run on these
documents, so they are not anchored on the model's output. The `notes` field in
each `expected.json` records why the label is what it is.

Cases the set was built to include: the most-mentioned contact is not the
economic buyer (`most-mentioned-not-buyer`); chat sentiment is positive and the
CRM notes are not (`chat-positive-crm-negative`); no real risk (`healthy`,
`risk_types: []`); a transcript long enough to be truncated, with the signal at
the end (`truncated-transcript`). The other nine cover the rest of the risk
taxonomy one type each.

`must_cite_sources` uses the document type labels `ingest.detect_type` assigns
(for example `MBR notes`, `CRM notes`, `Teams chat`, `CSV data`), since those
are the labels the brief's `section_sources` refers to.

Binary sources are generated by `evals/tools/make_media.py`; do not edit them by
hand.
